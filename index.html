Project Overview

Cash Parking Management System is a Command Line Interface app built in Python to help manage vehicle parking simply — from recording vehicle entry, vehicle exit, automatic parking fee calculation, to daily parking report. Built as a learning project to understand programming fundamentals before moving to GUI and Web apps.

Program Flow

How it runs.

1. Dashboard — Main menu
2. Vehicle Entry — Record plate + type + time
3. Vehicle List — Show active vehicles
4. Vehicle Exit — Calculate fee, mark exited
5. Exited List — Show exited vehicles
6. Daily Report — Total vehicles + total cash
